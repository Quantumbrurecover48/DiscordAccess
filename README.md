# zapret Discord YouTube для Windows

Проект содержит Windows-сборку на основе **zapret** и набор стратегий для работы с ограничениями сетевого доступа к **Discord** и **YouTube**. Результат зависит от сети, провайдера и выбранной стратегии; универсальная работоспособность не гарантируется.

Базовая версия публикуемых файлов — [1.10.2](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.2). Этот номер не означает, что версия является последней.

## Быстрый старт

1. Откройте [релиз 1.10.2](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.2) и скачайте опубликованный там архив.
2. В свойствах архива Windows при наличии установите флажок **«Разблокировать»** и примените изменения. При использовании 7-Zip или PeaZip этот шаг обычно можно пропустить.
3. Распакуйте архив в папку без кириллицы, пробелов и нестандартных символов, например:

   ```text
   C:\zapret\
   ```

4. Откройте распакованную папку.
5. Для ручного запуска запустите один из файлов `general*.bat` от имени администратора.
6. Если выбранная стратегия не работает, завершите её и последовательно протестируйте другие доступные варианты.

Перед запуском проверьте происхождение архива. Не используйте файлы из сторонних источников.

## Требования и ограничения

Проект предназначен для Windows и использует **WinDivert** — системный компонент для перехвата и обработки сетевого трафика. Защитное ПО может классифицировать WinDivert как потенциально нежелательный компонент или инструмент повышенного риска. Название обнаружения может содержать `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.

Если защитная программа блокирует компонент, сначала убедитесь, что архив получен из нужного репозитория и релиза. Не отключайте защиту системы и не добавляйте неизвестные файлы в исключения.

Для отдельных ресурсов может потребоваться настройка **Secure DNS / DNS over HTTPS**:

- в Chrome откройте настройки безопасного DNS и выберите конкретного поставщика;
- в Firefox включите DNS через HTTPS, выберите ручного поставщика и укажите адрес, например `https://dns.google/dns-query`;
- в Windows 11 Secure DNS настраивается в системных параметрах;
- на роутере Keenetic проверьте параметр **«Транзит запросов»**: его отключение может мешать работе Secure DNS на компьютере.

Подробности о WinDivert приведены в документации [zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B).

## Ручной запуск стратегий

Файлы `general*.bat` предназначены для ручного запуска стратегий. Названия доступных вариантов зависят от состава опубликованной версии. Разные сети и провайдеры могут обрабатывать соединения по-разному, поэтому при отсутствии результата следует остановить текущий вариант и проверить другие стратегии, включая доступные варианты `ALT`, `FAKE`, `SIMPLE FAKE` и `EXP`.

Запущенная стратегия обычно создаёт процесс `winws.exe`. Для запуска BAT-файлов и диагностических действий может потребоваться учётная запись администратора Windows.

## Работа через службу

Файл `service.bat` используется отдельно от ручного запуска и предоставляет пункты управления службой и диагностикой, включая:

- `Install Service` — добавление выбранной стратегии в автозапуск Windows;
- `Remove Services` — удаление созданных служб и WinDivert;
- `Check Status` — просмотр состояния служб и активной конфигурации;
- `Run Diagnostics` — поиск распространённых причин неправильной работы;
- `Run Tests` — запуск тестов доступных стратегий;
- `Game Filter` — управление обработкой игрового трафика;
- `IPSet Filter` — управление фильтрацией адресов из `ipset-all.txt`;
- `Replace active fakes` — выбор другого fake-файла из `bin`;
- `Update IPSet List` — обновление `ipset-all.txt`;
- `Update Hosts File` — обновление hosts для отдельных Telegram-ресурсов и голосовых подключений Discord;
- `Auto-Update Check` и `Check for Updates` — проверка доступности обновлений.

После выбора подходящей стратегии можно использовать `Install Service`. Это отличается от ручного запуска `general*.bat`: служба работает независимо от открытого окна BAT-файла и может запускаться вместе с Windows.

### IPSet Filter

Режим фильтрации может иметь следующие состояния:

- `none` — IP-адреса не используются для фильтрации;
- `loaded` — проверяются адреса из списка;
- `any` — под фильтрацию попадает любой IP.

После изменения параметров может потребоваться повторный запуск активной стратегии. Режим `ipset any` способен затронуть соединения, которые не должны обрабатываться, поэтому его не следует использовать постоянно без необходимости.

### Run Tests

Пункт `Run Tests` включает:

- **Standard tests** — проверку ресурсов из `utils/targets.txt`;
- **DPI checkers** — дополнительные проверки DPI для разных сетевых условий.

## Устранение проблем

### После запуска `general*.bat` не появляется результат

Проверьте, появился ли процесс `winws.exe`. Если он не запускается или сразу завершается:

1. запустите BAT-файл от имени администратора;
2. остановите текущую стратегию и попробуйте другую;
3. откройте `service.bat` → `Run Diagnostics`;
4. при необходимости ознакомьтесь с [Issue #522](https://github.com/Flowseal/zapret-discord-youtube/issues/522).

### Ни одна стратегия не работает

Откройте командную строку от имени администратора и выполните:

```cmd
netsh winsock reset
netsh int ip reset all
netsh winhttp reset proxy
ipconfig /flushdns
```

Перезагрузите компьютер и повторите проверку нескольких стратегий.

### Не работает Telegram Web или голосовой Discord

Откройте `service.bat` → `Update Hosts File`. Если программа предлагает обновить hosts вручную:

1. скопируйте предложенное содержимое;
2. откройте файл `hosts` с правами администратора;
3. добавьте необходимые строки;
4. сохраните файл и повторите проверку подключения.

### Discord не подключается

Проверьте настройку Secure DNS, запустите `service.bat` → `Run Diagnostics`, очистите кэш Discord и протестируйте несколько стратегий. Также проверьте веб-версию по адресу https://discord.com/app. Если она работает, проблема может быть связана с локальными данными приложения.

Дополнительное обсуждение: [Discussion #252](https://github.com/Flowseal/zapret-discord-youtube/discussions/252).

### YouTube не открывается

Проверьте настройку Secure DNS, смените стратегию и временно исключите влияние стороннего блокировщика рекламы. Дополнительное обсуждение: [Discussion #251](https://github.com/Flowseal/zapret-discord-youtube/discussions/251).

### Игра или приложение конфликтует с настройками

Проверьте состояние `Game Filter` и `IPSet Filter`. Для диагностики можно временно установить `Game Filter` в `disabled`, а `IPSet Filter` — в `none`. Если игре нужны определённые IP-адреса, их можно добавить в `ipset-all.txt`.

### Стратегия перестала работать

Сетевые условия могут меняться. Попробуйте другую стратегию, запустите `Run Diagnostics`, обновите IPSet и hosts, а затем повторите тестирование. Описание параметров стратегий доступно в документации оригинального [zapret](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

### Полное обновление

1. Сохраните собственные изменения и пользовательские списки.
2. Перезагрузите Windows.
3. Откройте `service.bat` → `Remove Services`.
4. Выполните `Run Diagnostics`.
5. Удалите старую папку проекта.
6. Скачайте архив из [раздела Releases](https://github.com/Flowseal/zapret-discord-youtube/releases).
7. При необходимости разблокируйте архив в его свойствах.
8. Распакуйте новую версию в отдельную папку.
9. Протестируйте несколько `general`-стратегий.
10. После выбора подходящей конфигурации при необходимости используйте `Install Service`.

### WinDivert остался в службах после удаления

Откройте `cmd` и выполните:

```cmd
driverquery | find "Divert"
```

Найдите имя соответствующей службы, затем выполните:

```cmd
sc stop название_службы
sc delete название_службы
```

Для Windows 7 сведения о версиях WinDivert находятся в разделе [`zapret-win-bundle/win7`](https://github.com/bol-van/zapret-win-bundle/tree/master/win7). Информация о специальной конфигурации WinDivert доступна в разделе [`windivert-hide`](https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide).

## Пользовательские списки

Дополнительные домены и IP-адреса можно указывать в следующих файлах:

- `list-general-user.txt` — пользовательские домены и поддомены;
- `list-exclude-user.txt` — домены-исключения;
- `ipset-all.txt` — IP-адреса и подсети;
- `ipset-exclude-user.txt` — исключения для IP-адресов и подсетей.

Файлы с суффиксом `-user` создаются автоматически при первом запуске `zapret` или `service.bat`.
